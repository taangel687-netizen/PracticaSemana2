Modo de color

La galería respeta la preferencia del sistema operativo (prefers-color-scheme) y cambia con una transición suave, sin recargar la página.

Acerca de esta galería

Este proyecto fue desarrollado como práctica del curso Desarrollo de Aplicaciones Web (IS093A), Unidad I: Desarrollo Web Frontend. Aplica HTML5 semántico, CSS3 avanzado (Grid, Flexbox, Container Queries, tipografía fluida) y validación de accesibilidad WCAG 2.1.
